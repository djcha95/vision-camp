# 교사 묶음 사진 추가 가이드

## 📁 파일 위치
`public/assets/staff/` 디렉토리에 각 그룹별 묶음 사진을 넣어주세요.

## 📝 파일명 규칙

각 그룹별로 1장의 묶음 사진을 준비해주세요:

### 파일명 목록
- `group-pastors.jpg` - 교역자 묶음 사진
- `group-executives.jpg` - 임원선생님 묶음 사진
- `group-vision1-teachers.jpg` - 비전1 담임선생님 묶음 사진
- `group-vision2-teachers.jpg` - 비전2 담임선생님 묶음 사진
- `group-ministry-team.jpg` - 활동선생님(사역팀) 묶음 사진

## 🖼️ 권장 사양
- **형식**: JPG 또는 PNG
- **비율**: 6000x1250 (약 4.8:1) 또는 유사한 가로형 비율
- **용량**: 500KB ~ 3MB 권장
- **해상도**: 6000px 너비 권장 (또는 유사한 고해상도)

## 💡 중요 사항
1. **사진에 이미 모든 정보가 포함되어 있습니다**
   - 사진에 "비전캠프를 소개합니다" 같은 텍스트와 선생님 이름이 모두 포함되어 있어야 합니다
   - 웹사이트에서는 추가 텍스트를 표시하지 않습니다
2. 파일명은 정확히 위의 이름과 동일하게 해주세요
3. 사진이 잘리지 않도록 전체가 보이도록 설정되어 있습니다
4. 모든 선생님들이 잘 보이도록 촬영해주세요

## ✅ 확인 방법
1. `public/assets/staff/` 폴더에 묶음 사진 파일 추가
2. 브라우저에서 페이지 새로고침 (F5 또는 Ctrl+Shift+R)
3. Staff 섹션에서 각 그룹별 사진이 전체가 잘 보이는지 확인
